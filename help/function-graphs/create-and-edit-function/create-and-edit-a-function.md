# Crear y editar una función

## Crear una función

Para crear una función, solo tiene que hacer clic en el icono de función ![](create-and-edit-a-function.resources/create-and-edit-a-function-01.png) y elegir &quot;**Función vacía**&quot;.

![](create-and-edit-a-function.resources/create-and-edit-a-function-02.png)

## Editar una función

Una vez creada una función, puede modificarla haciendo clic de nuevo en el icono de función o eligiendo Editar en la lista desplegable.

![](create-and-edit-a-function.resources/create-and-edit-a-function-03.png)

A continuación, entrará en el modo de función del gráfico.

## El gráfico de funciones

El gráfico de funciones funciona de la misma manera que otros tipos de gráficas en Designer: con un editor de nodos.

## Crear nodos

Puede crear nodos haciendo clic con el botón derecho en el gráfico y eligiendo &quot;Agregar elemento&quot;, o pulsando la barra espaciadora:

![](create-and-edit-a-function.resources/create-and-edit-a-function-04.png){width="600px"}

## Definir una salida

Contrariamente al gráfico del Substance, la función no tiene el nodo &quot;Salida&quot;, debe especificar qué nodo del gráfico es la salida de la función.

Puede establecer un resultado haciendo clic con el botón secundario en un nodo y eligiendo <b>&quot;Establecer como nodo de salida&quot;.</b>

El nodo definido como salida se volverá amarillo.

>[!NOTE]
>
> **Tipo de salida**
> 
> El nodo que desea establecer como salida debe contener el mismo tipo de valor que el parámetro que controla. Si no es así, la opción &quot;Establecer como nodo de salida&quot; aparecerá atenuada.

>[!WARNING]
>
> Una función debe tener una salida para poder funcionar. Verá una advertencia en el gráfico si su función no tiene ningún conjunto de salida.
