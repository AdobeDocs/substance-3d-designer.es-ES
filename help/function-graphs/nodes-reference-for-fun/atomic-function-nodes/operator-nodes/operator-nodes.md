# Nodos de operador

Los nodos de operador permiten realizar operaciones matemáticas clásicas en nodos de entrada:

![](../../../../assets/image2015-12-23-10-55-31.png)

>[!NOTE]
>
> Para la división y el módulo, el divisor es la entrada inferior.
> 
> Para la resta, el sustrato es también la entrada inferior.
