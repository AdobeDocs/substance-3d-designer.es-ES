# Nodos de colada

Los nodos de conversión se utilizan para convertir un nodo de un tipo a otro tipo:

## ¿Cómo se usa un nodo de conversión?

Solo tiene que seleccionar el nodo de conversión que corresponda a la longitud del nodo que desea convertir.
