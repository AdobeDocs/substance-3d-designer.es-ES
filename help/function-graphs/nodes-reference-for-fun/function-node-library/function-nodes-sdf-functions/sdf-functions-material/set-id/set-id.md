## Descripción

Defina el ID de material de una escena SDF.

Este valor se puede recuperar para todas las formas SDF salpicadas en la salida *Splatter UVW* de la [Dispersión de formas v2](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md).
