## Descripción

Defina el metal del material de una escena SDF.

Este valor se puede recuperar para todas las formas SDF salpicadas en la salida *SDF metalness* de la [Forma splatter v2](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md).
