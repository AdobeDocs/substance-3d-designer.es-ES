# Descripción general de nodos de función

Esta página proporciona una visión general completa de todos los nodos de función y explica el código de color utilizado para los tipos de datos de función. Puede hacer clic en las páginas más detalladas con explicaciones adicionales.

Se puede acceder a estos nodos de función haciendo clic con el botón derecho en el editor de funciones de gráfico y eligiendo Elemento, pulsando la barra espaciadora o el tabulador en una función o a través de la sección Funciones de la biblioteca.
