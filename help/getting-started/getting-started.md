# Introducción

Aprenda a utilizar el software:

* [Activación y licencias](../getting-started/activation-and-licenses/activation-and-licenses.md): Esta página contiene información sobre cómo activar y administrar las licencias para que pueda empezar a usar Designer.
* [Requisitos del sistema](../getting-started/system-requirements/system-requirements.md): En esta página se enumeran los requisitos del sistema y la información de compatibilidad de hardware.
* [Información general](../getting-started/overview/overview.md): Esta página proporciona una descripción general de Substance 3D Designer (https://www.adobe.com/es/products/substance3d-designer.html), una comparación con las demás aplicaciones del ecosistema Substance, y un desglose del tipo de archivos y recursos con los que trabajará.
* [Descripción del flujo de trabajo](../getting-started/workflow-overview/workflow-overview.md): En esta página se explica el concepto de flujo de trabajo basado en nodos y se resumen los tres tipos principales de gráficos que puede crear en Designer.
* [Métodos abreviados](../getting-started/shortcuts/shortcuts.md): En esta página encontrará una descripción general de todos los métodos abreviados de Substance 3D Designer.
* [Tutoriales y aprendizaje](../getting-started/tutorials-learning/tutorials-learning.md): Si prefiere implicarse de lleno con vídeos y otros materiales de aprendizaje más específicos, estos tutoriales son un buen punto para comenzar.
