# Problemas de interfaz de usuario

Esta página enumera problemas técnicos relacionados con la [interfaz de usuario](../../interface/interface.md) de Substance 3D Designer y ofrece pasos de solución de problemas para cada uno.

## La escala de la interfaz es incorrecta

<table>
<tr style="border: 0;">
<td style="border: 0;" valign="top">

**![(出 错)](user-interface-issues.resources/error.svg) Problema**

Los elementos de la interfaz de usuario son demasiado pequeños o demasiado grandes.

</td>
<td style="border: 0;" valign="top">

**![(滴 答)](user-interface-issues.resources/check.svg) Pasos recomendados**

Designer adquiere la escala específica de los elementos de la interfaz de usuario *del sistema operativo*. Por lo tanto, cualquier ajuste en la escala de la interfaz de usuario debe realizarse en la configuración de visualización del sistema operativo.

Para garantizar que la configuración de visualización se aplique correctamente en Designer, *cierre sesión* de la sesión de usuario del sistema operativo y vuelva a iniciar sesión después de cambiar esta configuración.

</td>
</tr>
</table>
