# Versión 2019.3 (9.3)

**Substance Designer 2019.3** presenta la administración de color con compatibilidad con actualizaciones de bakeres OpenColorIO y mejoradas y un nuevo nodo de atlas scatter.

Fecha de publicación: *19 de diciembre de 2019*

## Funciones principales

### Compatibilidad con la gestión de color y OpenColorIO

![](../../../assets/banner-color-management.jpg)

Substance Designer ahora admite la gestión de color, que permite controlar cómo se interpretan y transforman los colores. Esta característica es compatible con [OpenColorIO](https://opencolorio.org/), un sistema de administración de color muy usado en la industria del entretenimiento y los efectos visuales.

* **Configurando la administración de color en la configuración principal**\
  De forma predeterminada, el Substance Designer se configurará en modo &quot;heredado&quot;, lo que significa que no cargará ninguna configuración específica y seguirá funcionando como antes. Para cambiar a OpenColorIO, por ejemplo, solo tiene que ir directamente a la configuración principal y, a continuación, en la configuración del proyecto para configurarla y habilitarla.

  ![](../../../assets/sd-color-management-settings.png){width="600px"}
* **La administración de color se aplica de 3 maneras diferentes**\
  Las diferentes partes de la aplicación reciben la gestión de color, que tiene diferentes implicaciones:

  * **2D y Vista 3D**\
    Tanto la ventana gráfica de Opengl en tiempo real como Iray se pueden gestionar por color. Esto permite previsualizar en contexto el material y el texturizado. El perfil de color se puede cambiar fácilmente mediante el menú desplegable dedicado. También es posible mostrar la vista en Gamma lineal para previsualizarla sin corrección de color.

    ![](../../../assets/color-2d-view.png){width="400px"}

    ![](../../../assets/color-3d-view.png){width="400px"}
  * **Entradas y salidas de gráficos y exportación de mapa de bits**\
    Al leer y escribir imágenes de mapa de bits a la entrada y salida de un gráfico, la gestión de color puede ajustar la imagen y convertirla para que funcione en las condiciones adecuadas. Esto se puede controlar en la preferencia principal de mapa de bits en el gráfico y se puede modificar en el cuadro de diálogo de exportación durante el proceso de exportación. Guardar una imagen del vista 2D también ofrecerá una forma de elegir el espacio de color.

    ![](../../../assets/color-export-outputs.png){width="400px"}

    ![](../../../assets/color-export-2d.png){width="505px"}

### Nueva curvatura del Baker de malla

![](../../../assets/banner-curvature-1.png)

La curvatura del baker de malla se ha rehecho desde cero. Ahora aprovecha el trazado de rayos, que permite la aceleración de la GPU, pero también añade la compatibilidad con intersecciones de malla.

Para obtener más información, consulte la documentación de [Curvatura de malla](https://experienceleague.adobe.com/en/docs/substance-3d/bakers/bakers-settings/curvature-from-mesh).

>[!NOTE]
>
> El baker Curvatura desde malla anterior ya no se usa. Se recomienda cambiar a la nueva versión.

### Oclusión ambiental mejorada desde el Baker de malla

![](../../../assets/banner-ao-v2.png)

El baker Oclusión ambiental de malla ahora tiene un nuevo ajuste llamado &quot;Plano de tierra&quot; que simula un plano bajo la malla para producir oclusión de tierra. Esto puede ayudar a producir un resultado de aspecto más interesante para la geometría estática o los objetos no orgánicos. El plano de tierra se encuentra en la parte inferior del cuadro delimitador de la malla de forma predeterminada, pero se puede seguir avanzando con una configuración específica.

Para obtener más información, consulte la documentación de [Oclusión ambiental de Mesh](https://experienceleague.adobe.com/en/docs/substance-3d/bakers/bakers-settings/ambient-occlusion-from-mesh).

### Editor de propiedades y ajustes preestablecidos mejorado

![](../../../assets/banner-presets.png)

Se ha mejorado el editor de propiedades, así como el editor de ajustes preestablecidos:

* **Modo de vista previa más rápido**\
  El cambio al modo de previsualización al editar parámetros de gráficos ahora es mucho más rápido, especialmente en gráficos con muchos parámetros expuestos. El modo de vista previa es ahora una pestaña dedicada que facilita el ir y venir entre el editor de parámetros y su vista previa.
* **Editor de ajustes preestablecidos reprocesado**\
  La forma en la que se gestionan los ajustes preestablecidos en Substance Designer es ahora mucho más fácil y rápida: el editor de ajustes preestablecidos ahora tiene su pestaña dedicada y cada ajuste preestablecido ahora enumera los parámetros que afectan.
* **Visible si ahora se tiene en cuenta para gizmos de transforma 2D**\
  Cuando un gizmo de transformar 2D tiene una condición Visible If, ahora se puede ocultar en la vista 2D, lo que lo hace contextual a los parámetros.

### Nuevo contenido

![](../../../assets/banner-content-8.jpg)

En esta versión presentamos el nuevo nodo **Atlas scatter**. Este nodo permite leer una imagen atlas (una imagen que contiene subimágenes) y separar automáticamente su contenido en componentes individuales que luego se pueden dispersar aleatoriamente. Este nodo se puede utilizar, por ejemplo, para colocar ramas y hojas en un material de suelo de dirt. [Substance Source](https://source.substance3d.com/allassets?q=atlas) ahora incluye muchos materiales de Atlas que se pueden dispersar con este nuevo nodo.

>[!WARNING]
>
> Esta versión ya no es compatible con CentOS 6.x.\
> En CentOS 7.x, es posible que la aplicación no se inicie debido a algunos problemas de dependencias. Para corregir el problema, actualice el sistema o copie la [siguiente biblioteca](https://centos.pkgs.org/7/centos-x86_64/freetype-2.8-12.el7.x86_64.rpm.html) en la carpeta de instalación.
