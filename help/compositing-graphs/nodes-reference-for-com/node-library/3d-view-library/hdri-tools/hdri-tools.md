# Herramientas HDRI

Las herramientas HDRI son nodos destinados a manipular y crear imágenes HDRI. Específicamente eso significa que estos nodos tienen funcionalidad para trabajar y generar valores de Alto rango dinámico correctos, así como nodos que dan cuenta y compensan la asignación de proyección esférica.
