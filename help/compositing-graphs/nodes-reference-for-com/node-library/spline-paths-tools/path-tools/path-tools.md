# Herramientas de Ruta

Las herramientas de trazado son un conjunto de nodos para generar y ajustar trazados, así como para convertirlos en splines para la dispersión o deformación complejas de imágenes.

Los trazados son una serie de puntos conectados en líneas rectas.

Echa un vistazo a este tutorial para empezar:

>[!TIP]
>
> Se recomienda obtener información sobre [cómo trabajar con Path y Herramientas de spline](../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/working-with-path-and-spl/working-with-path-and-spline-tools.md) para aprovechar al máximo el conjunto de herramientas.
> 
> Para usuarios avanzados, la [Especificación de formato de trazados](../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/path-tools/paths-format-spe/paths-format-specifications.md) explica cómo se codifican los datos de los trazados en imágenes en color y proporciona sugerencias para manipular estos datos directamente.
