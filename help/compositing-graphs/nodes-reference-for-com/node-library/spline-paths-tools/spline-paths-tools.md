# Herramientas de spline y trazado

Las herramientas Spline y Path son una colección de nodos para trabajar con trazados y splines en gráficas de Substance:

<b>Los trazados</b> son una serie de puntos conectados en líneas rectas.

Las <b>splines</b> son curvas suaves cuyas trayectorias están moldeadas por puntos de control y tangentes de esos puntos. Cada punto también controla los atributos de height y thickness de una spline, que se utilizan para controlar la asignación, deformación y dispersión de imágenes.

Esta categoría contiene las siguientes subcategorías:

* [Herramientas de spline](../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/spline-tools/spline-tools.md)\
  Nodos para generar y ajustar splines, así como para utilizarlos para asignar, dispersar o deformar imágenes.
* [Herramientas de trazado](../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/path-tools/path-tools.md)Nodos para generar y ajustar trazados, así como para convertirlos en splines para la dispersión o deformación complejas de imágenes.
