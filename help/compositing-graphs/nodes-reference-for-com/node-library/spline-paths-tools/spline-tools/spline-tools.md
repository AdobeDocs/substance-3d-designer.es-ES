# Herramientas de Spline

Las herramientas de spline son un conjunto de nodos para generar y ajustar splines, así como para utilizarlas para asignar, dispersar o deformar imágenes.

Las splines son curvas suaves cuyas trayectorias tienen la forma de puntos de control y tangentes de esos puntos. Cada punto también controla los atributos de height y thickness de una spline, que se utilizan para controlar la asignación, deformación y dispersión de imágenes.
