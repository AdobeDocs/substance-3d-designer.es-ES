# Generadores de máscaras

Esta categoría contiene una selección de nodos que generan máscaras en blanco y negro. En función de la información de mapa con bake, generan máscaras que se pueden utilizar para fusionar materiales y otros efectos. Estos nodos son similares a [Máscaras inteligentes](https://experienceleague.adobe.com/es/docs/substance-3d-painter/using/features/smart-materials-and-masks) y [Generadores](https://experienceleague.adobe.com/es/docs/substance-3d-painter/using/content/creating-custom-effects/generators) en Substance Painter.

Todos estos nodos requieren [mapas con bake,](../../../../../bakers/bakers.md) ya que sin [mapas con bake](../../../../../bakers/bakers.md) no habrá mucho resultado.

El uso principal previsto es usar estos generadores de máscaras con [materiales multicanal](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/material-filters.md). Una vez generada una máscara, se usa como máscara de fusión para [Fusión de material](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/blending-material/material-blend/material-blend.md).

Algunos nodos interesantes en esta categoría son:

* [Óxido goteo](../../../../../compositing-graphs/nodes-reference-for-com/node-library/mesh-based-generators/mask-generators/dripping-rust/dripping-rust.md)
* [Daños en los bordes](../../../../../compositing-graphs/nodes-reference-for-com/node-library/mesh-based-generators/mask-generators/edge-damages/edge-damages.md)
* [De abajo arriba](../../../../../compositing-graphs/nodes-reference-for-com/node-library/mesh-based-generators/mask-generators/bottom-to-top/bottom-to-top.md)
* [Creador de máscaras](../../../../../compositing-graphs/nodes-reference-for-com/node-library/mesh-based-generators/mask-generators/mask-builder/mask-builder.md)
