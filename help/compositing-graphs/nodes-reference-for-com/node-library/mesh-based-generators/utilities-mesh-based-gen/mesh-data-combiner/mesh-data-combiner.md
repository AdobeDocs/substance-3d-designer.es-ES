## Descripción

Este es un nodo muy simple que &quot;empaqueta&quot; datos de malla horneados en un solo grupo, para su uso con &quot;Modo de material compacto&quot;.

Este nodo es principalmente un ayudante que facilita el trabajo con muchas entradas predefinidas en ciertos nodos de la galería, como [Material Mesh Data Blender](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/mesh-based-generators/utilities-mesh-based-gen/material-mesh-data-ble/material-mesh-data-blender.md). Te permite evitar conectar manualmente todo.
