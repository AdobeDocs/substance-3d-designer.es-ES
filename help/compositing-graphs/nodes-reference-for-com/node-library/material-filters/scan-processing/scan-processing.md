Esta categoría está pensada para satisfacer tus necesidades de procesamiento de fotos y escaneos en materiales PBR completos y de mosaico. Contiene una gran variedad de herramientas con funciones para eliminar la iluminación, recortar bordes y mejorar el mosaico.
