# Fusión (Material)

La categoría Fusión es una de las categorías de materiales multicanal más importantes. Contiene nodos destinados a combinar, conmutar y mezclar materiales que constan de múltiples salidas simultáneas.

Estos nodos pueden ahorrar una gran cantidad de trabajo, pero asegúrate de que entiendes perfectamente [los modos de creación de vínculos](../../../../../interface/the-graph-view/link-creation-modes/link-creation-modes.md) para utilizarlos correctamente.

Los siguientes nodos son buenos para empezar:

* [Fusión de varios materiales](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/blending-material/multi-material-blend/multi-material-blend.md)
* [Mezcla de ajuste de material](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/blending-material/material-adjustment-blend/material-adjustment-blend.md)
