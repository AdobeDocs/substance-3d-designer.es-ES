## Descripción

Este es un nodo de ayuda de preajuste rápido para devolver los colores de reflejo correctos para algunos metales **puros** predefinidos. Se puede utilizar en el color base para el modelo metálico o en el canal de Specular para el modelo Specular/Brillo.

Este nodo es útil cuando desea un punto de partida para un metal puro y le permite evitar la selección de color de un gráfico.

## Parámetros

* **Color de metal**: *Oro, Plata, Aluminio, Hierro, Cobre, Titanio, Níquel, Cobalto, Platino* Elige un valor de metal predefinido.
