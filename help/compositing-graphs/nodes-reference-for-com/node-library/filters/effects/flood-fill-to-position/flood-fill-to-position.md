## Descripción

Genera un mapa de posición por mosaico a partir de una base de [Flood Fill](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/flood-fill/flood-fill.md).

El color de cada mosaico representa su centro de coordenadas X e Y, almacenado en los canales Rojo y Verde. Este mapa está pensado como una base para cálculos adicionales, en lugar de un mapa listo para usar.

## Parámetros

*No hay parámetros.*
