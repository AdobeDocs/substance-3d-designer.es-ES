## Descripción

Activa la entrada mediante un exponente especificado. Es similar a ajustar los [niveles](../../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/levels/levels.md) del punto medio, pero en un paquete más sencillo. Útil también para cuando se desea realizar una operación matemática exacta de potencia.

Importante: asegúrese de utilizar la versión correcta, dependiendo de si tiene una entrada en color o en escala de grises.

</td>

## Parámetros

|  |  |
|:---|:---|
| <b>exponente</b> <i>0.0 - 10.0</i> | Exponente con el que se alimenta la entrada. |
