# Desplazamiento del histograma

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![](../../../../../../assets/histogram-shift-1.png){width="128px"}

<b>En:</b> Filtros > Ajustes

</td>
<td width="100.00%" style="border: 0;" valign="top">

## Descripción

Cambia por completo todo el rango de la imagen, ajustándose cuando se alcanzan los límites de rango.

[Haz clic aquí para ver un vídeo de la Academia de Substance sobre el cambio de histograma.](https://youtu.be/p9wcmJBFyGA?t=492)

</td>
</tr>
</table>

<a name="parameters"></a>

## Parámetros

|  |  |
|:---|:---|
| <b>Posición</b> <i>0.0 - 1.0</i> | Cuánto se debe desplazar la entrada. 1.0 es una rotación completa y es igual a 0.0. |
