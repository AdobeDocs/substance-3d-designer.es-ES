## Descripción

Un sencillo ajuste de contraste y luminosidad (brillo).

## Parámetros

* **Contraste**: *-1.0 - 1.0*\
  Ajusta el contraste del resultado.
* **Luminosidad**: *-1.0 - 1.0*\
  Ajusta la luminosidad (brillo) del resultado.
