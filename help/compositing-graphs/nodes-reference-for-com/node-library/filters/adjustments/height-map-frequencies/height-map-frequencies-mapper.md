**En:** *Filtros/Ajustes*

**Simple**

</td>

## Descripción

Separa las frecuencias de un mapa de altura en dos mapas separados: uno con diferencias a gran escala y otro con diferencias a pequeña escala.

## Parámetros

* **Relieve**: *0.0 - 32.0* Controla el tamaño de detalle de la salida de Desplazamiento.
