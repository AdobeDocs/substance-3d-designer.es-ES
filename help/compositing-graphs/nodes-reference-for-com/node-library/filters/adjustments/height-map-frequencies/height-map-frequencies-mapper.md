# Asignador de frecuencias de mapa de height

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

<b>En:</b> Filtros > Ajustes

</td>
<td width="100.00%" style="border: 0;" valign="top">

## Descripción

Separa las frecuencias de un mapa de altura en dos mapas separados: uno con diferencias a gran escala y otro con diferencias a pequeña escala.

</td>
</tr>

## Parámetros

|  |  |
|:---|:---|
| <b>Relieve</b> <i>0.0 - 32.0</i> | Controla el tamaño de detalle de la salida de Desplazamiento. |
