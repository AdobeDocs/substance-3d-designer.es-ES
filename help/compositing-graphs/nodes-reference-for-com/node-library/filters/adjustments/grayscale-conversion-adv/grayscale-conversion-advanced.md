<a name="parameters"></a>

## Parámetros

|  |  |
|:---|:---|
| <b>Tipo De Escala De Grises</b> <i>Desaturación, Luminancia, Promedio, Máx, Mín</i> | La desaturación establece el valor de saturación en 0, la luminancia utiliza grosores de luminancia oficiales, el promedio es el mismo que el nodo atómico y Max y Min utilizarán el valor más brillante para cada canal, respectivamente. |
