# Ajustes

Esta es una de las principales categorías de Filtro, con nodos destinados a ajustar los valores y rangos de entradas de diversas maneras. La mayoría de los nodos son una forma avanzada y ampliada de usar los nodos [Levels](../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/levels/levels.md) y [Blend](../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/blend/blend.md), y están pensados como métodos abreviados más inteligentes para ciertas operaciones.

Use la <b>lista de navegación de la izquierda</b> para examinar todos los nodos en Ajustes.
