# Mosaico

La categoría Mosaico contiene nodos utilizados para mejorar el mosaico de texturas. Tenga en cuenta que hay otros nodos disponibles para esto en [Procesamiento de digitalización](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/scan-processing/scan-processing.md).

Use la lista de navegación de la izquierda para examinar todos los nodos bajo <b>Mosaico</b>.

Hay dos nodos en esta categoría:

* [Hacer que parche de azulejo](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/tiling/make-it-tile-patch/make-it-tile-patch.md)
* [Hacer que la fotografía en mosaico](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/tiling/make-it-tile-photo/make-it-tile-photo.md)
