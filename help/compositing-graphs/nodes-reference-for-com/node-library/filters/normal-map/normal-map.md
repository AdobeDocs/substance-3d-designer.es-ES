# Mapa de normales

Esta categoría sólo contiene nodos para procesar y trabajar con Normalmaps. Son imprescindibles cuando se desea que el procesamiento de la asignación Normal sea matemáticamente correcto, para evitar problemas de espacio de Tangente.

Use la <b>lista de exploración de la izquierda</b> para examinar todos los nodos bajo Mapa de normales.

Algunos nodos muy útiles en esta categoría son:

* [Combinación normal](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/normal-map/normal-combine/normal-combine.md)
* [Sobel normal](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/normal-map/normal-sobel/normal-sobel.md)
* [Normalizar normal](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/normal-map/normal-normalize/normal-normalize.md)
