# Desenfoques

La categoría Desenfoques se expande en [el nodo estándar Desenfoque de cuadro atómico](../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/blur/blur.md). Contiene desenfoques más avanzados y de mayor calidad que tienen varios usos.

Ten en cuenta que todos los nodos de Desenfoque de biblioteca vienen en una versión en escala de grises y en color. Intente utilizar la versión que sea adecuada para la entrada.

Algunos buenos desenfoques para comprobar hacia fuera:

* [Desenfocar alta calidad](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/blurs/blur-hq/blur-hq.md)
* [Desenfoque de pendiente](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/blurs/slope-blur/slope-blur.md)
