## Descripción

Degradado de doble cara simple y suave. Proporciona un degradado perfecto negro-blanco-negro con interpolación perfecta.

A pesar de su simplicidad, es muy útil y puede servir para muchos propósitos. Pruébelo junto con un [Histograma](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/histogram-scan/histogram-scan.md), por ejemplo.

## Parámetros

* **Mosaico**: *1 - 16*\
  Define la cantidad de veces que el resultado debe aparecer en mosaico.
* **Rotación**: **0, 90°** Cambia la dirección de izquierda a derecha a superior-inferior, o viceversa.
