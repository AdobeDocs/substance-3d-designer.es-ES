## Descripción

Patrón de ladrillo simple, consulta [Generador de ladrillos](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/brick-generator/brick-generator.md) o [Tile Generator](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/tile-generator/tile-generator.md) para obtener más opciones.

## Parámetros

* **Mosaico**: *1 - 16*\
  Define la cantidad de veces que el resultado debe aparecer en mosaico.
* **Smoothness Edge**: *0.0 - 1.0* Mezcla entre bordes ásperos y suaves.
* **Ancho de intersticio**: *0.0 - 1.0* Establece el intersticio (tamaño de hueco).
* **Expansión no cuadrada**: *Falso/Verdadero*\
  Permite la compensación de aplastamiento y estiramiento con proporciones no cuadradas.
