## Descripción

Genera una forma de polígono de degradado suave con opciones de ajuste. Consulte [Polígono 1](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/polygon-1/polygon-1.md) para obtener una versión más avanzada.

## Parámetros

|  |  |
|:---|:---|
| <b>Lados</b> <i>3 - 32</i> | Cantidad de lados. |
| <b>Escala</b> <i>0.0 - 1.0</i> | Define la escala global. |
| <b>Rotación</b> <i>0.0 - 1.0</i> | Gira toda la forma. |
| <b>Curva</b> <i>-1.0 - 1.0</i> | Modifica la curva del perfil de degradado. |
| <b>Degradado</b> <i>0.0 - 1.0</i> | Ajusta el contraste del degradado. |
| <b>Invertir degradado</b> <i>Falso/Verdadero</i> | Invierte la dirección del degradado. |
| <b>Escala automática</b> <i>Falso/Verdadero</i> | Se ajusta para encajar en el lienzo con los ajustes predeterminados. |
| <b>Expansión no cuadrada</b> <i>Falso/Verdadero</i> | Permite la compensación de aplastamiento y estiramiento con proporciones no cuadradas. |
