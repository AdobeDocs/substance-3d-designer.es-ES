## Descripción

Genera una forma de polígono de degradado suave con opciones de ajuste. Consulte [Polígono 1](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/polygon-1/polygon-1.md) para obtener una versión más avanzada.

## Parámetros

* **Lados**: *3 - 32* Cantidad de lados.
* **Escala**: *0.0 - 1.0* Establece la escala global.
* **Rotación**: *0.0 - 1.0* Gira toda la forma.
* **Curva**: *-1.0 - 1.0* Modifica la curva del perfil de degradado.
* **Degradado**: *0.0 - 1.0* Ajusta el contraste del degradado.
* **Invertir degradado**: *Falso/Verdadero* Invierte la dirección del degradado.
* **Escala automática**: *Falso/Verdadero* Ajusta para ajustarse en lienzo con configuración predeterminada.
* **Expansión no cuadrada**: *Falso/Verdadero*\
  Permite la compensación de aplastamiento y estiramiento con proporciones no cuadradas.
