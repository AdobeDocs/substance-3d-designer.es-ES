## Descripción

Patrón simple parecido a un paño. Puede ser utilizado para malla, tela u otro Height orgánico- y Detailmaps. Consulte también [Fibres 1](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/fibers-1/fibers-1.md) para obtener una versión más pequeña.

## Parámetros

* **Mosaico**: *1 - 16*\
  Define la cantidad de veces que el resultado debe aparecer en mosaico.
* **Expansión no cuadrada**: *Falso/Verdadero*\
  Permite la compensación de aplastamiento y estiramiento con proporciones no cuadradas.
