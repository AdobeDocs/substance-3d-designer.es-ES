# Degradado circular

<table>

<td width="33.33%" style="border: 0;" valign="top">

<b>En:</b> Generadores de Textura > Patrones

</td>
<td width="100.00%" style="border: 0;" valign="top">

## Descripción

Crea una transición de degradado en escala de grises definida por dos puntos personalizados de forma circular. La transición no es de a a b, sino como una revolución alrededor del primer punto, comenzando y terminando en el segundo punto. Ten en cuenta que los resultados nunca se segmentarán.

</td>
</tr>
</table>

<a name="parameters"></a>

## Parámetros

|  |  |
|:---|:---|
| <b>Punto 1</b> | El primer punto para girar el degradado no tiene que estar centrado |
| <b>Punto 2</b> | Segundo punto para que el degradado comience y termine en. |
| <b>Expansión no cuadrada</b> <i>Falso/Verdadero</i> | Active la compensación de aplastamiento y estiramiento con proporciones que no sean de cuadrados. |
