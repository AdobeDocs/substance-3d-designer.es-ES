## Descripción

Este nodo genera un patrón de trama simple con algunas opciones. Permite un mayor control que los patrones de tejido predefinidos y presenta un patrón que no se puede lograr con otros nodos.

</td>
</tr>

<a name="parameters"></a>

## Parámetros

|  |  |
|:---|:---|
| <b>Mosaico X</b> <i>1 - 20</i> | Establece cuántos bloques se repiten en el eje X. |
| <b>Mosaico Y</b> <i>1 - 20</i> | Establezca cuántos bloques se repiten en el eje Y. |
| <b>Forma</b> <i>0.0 - 1.0</i> | Define el perfil de height de la curva de la puntada. |
| <b>Tejer</b> <i>1 - 10</i> | Define cuántos puntos por bloque. |
| <b>Hueco</b> <i>0.0 - 1.0</i> | Define el espacio entre puntos en los ejes X e Y. |
| <b>Expansión no cuadrada</b> <i>Falso/Verdadero</i> | Permite la compensación de calabaza y estira con proporciones no cuadradas. |
