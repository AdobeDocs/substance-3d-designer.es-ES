## Descripción

Degradado lineal simple en blanco y negro. Proporciona un resultado perfectamente suave e interpolado para una transición de degradado perfecta.

A pesar de su simplicidad, este es un patrón extremadamente útil que se puede utilizar como un bloque de construcción con muchos otros nodos! Pruébelo junto con un [Histograma](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/histogram-scan/histogram-scan.md), por ejemplo.

## Parámetros

|  |  |
|:---|:---|
| <b>Mosaico</b> <i>1 - 16</i> | Define la cantidad de veces que el resultado debe aparecer en mosaico. |
| <b>Rotación</b> <i>0°, 90°, 180°, 270°</i> | Gira a lo largo de un ángulo predefinido. Cambia la dirección del degradado. |
