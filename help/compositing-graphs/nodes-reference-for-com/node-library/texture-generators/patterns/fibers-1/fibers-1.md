## Descripción

Patrón de fibra simple. Se puede usar en [Substance 3D Designer](https://www.adobe.com/es/products/substance3d-designer.html) para obtener mapas de altura y detalles de cuerda, malla o tela.

<a name="parameters"></a>

## Parámetros

|  |  |
|:---|:---|
| <b>Mosaico</b> <i>1 - 16</i> | Define la cantidad de veces que el resultado debe aparecer en mosaico. |
| <b>Expansión no cuadrada</b> <i>Falso/Verdadero</i> | Permite la compensación de aplastamiento y estiramiento con proporciones no cuadradas. |
