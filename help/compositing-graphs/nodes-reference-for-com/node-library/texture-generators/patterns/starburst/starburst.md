<a name="parameters"></a>

## Parámetros

|  |  |
|:---|:---|
| <b>Ramas</b> <i>3 - 512</i> | Cantidad de ramas para el efecto. |
| <b>Cantidad de desenfoque</b> <i>0.0 - 32.0</i> | Controla la cantidad total de desenfoque o suavidad. |
| <b>Aleatoriedad</b> <i>0.0 - 1.0</i> | Establece la aleatoriedad axial, gira las ramas aleatoriamente alrededor del centro. |
| <b>Tamaño Mín.</b> <i>0.0 - 1.0</i> | Define el tamaño mínimo para la variación. |
| <b>Tamaño máximo</b> <i>0.0 - 2.0</i> | Establece el tamaño máximo y controla la escala global si no se utiliza variación. |
| <b>Variación de tamaño</b> <i>0.0 - 1.0</i> | Introduce la escala aleatoria por rama. |
| <b>Mosaico</b> <i>1 - 16</i> | Define la cantidad de veces que el resultado debe aparecer en mosaico. |
