## Descripción

Genera un efecto de arranque simple, con parámetros de ajuste disponibles.

## Parámetros

* **Ramas**: *3 - 512* Cantidad de ramas para el efecto.
* **Cantidad de desenfoque**: *0.0 - 32.0* Controla la cantidad total de desenfoque o suavidad.
* **Aleatoriedad**: *0.0 - 1.0* Establece la aleatoriedad axial, gira las ramas aleatoriamente alrededor del centro.
* **Tamaño Mín.**: *0.0 - 1.0* Establece un tamaño mínimo para la variación.
* **Tamaño máximo**: *0.0 - 2.0* Establece el tamaño máximo y controla la escala global si no se usa variación.
* **Variación de tamaño**: *0.0 - 1.0* Introduce una escala aleatoria por rama.
* **Mosaico**: *1 - 16*\
  Define la cantidad de veces que el resultado debe aparecer en mosaico.
