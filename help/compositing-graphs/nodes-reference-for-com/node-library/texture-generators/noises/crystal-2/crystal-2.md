## Descripción

Genera un angular, un patrón similar al pliegue de tela. Similar a [Reducir ruido](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/creased/creased.md).

Esto es un poco de ruido de nicho: puede ser útil para casos raros en los que se busca este tipo de detalle, como cuando se recrea patrones de mármol sutiles o se hace tela.

</td>
</tr>
</table>

<a name="parameters"></a>

## Parámetros

|  |  |
|:---|:---|
| <b>Escala</b> <i>1 - 16</i> | Establece la escala global del efecto. |
| <b>Desorden</b> <i>0.0 - 1.0</i> | Desplaza la fase del ruido para introducir pequeñas variaciones. |
| <b>Expansión no cuadrada</b> <i>Falso/Verdadero</i> | Permite la compensación de aplastamiento y estiramiento con proporciones no cuadradas. |
