# Referencia de nodos para gráficos de Substance

Como Substance 3D Designer es un software de texturizado basado en nodos, hay muchos nodos diferentes a su disposición. Esta sección tiene como objetivo explicar los diferentes tipos y documentar todos los nodos suministrados con el software.

Lo que llamamos &quot;nodo&quot; dentro de SD, se puede dividir en 2 grupos principales:

* [Los nodos atómicos](../../compositing-graphs/nodes-reference-for-com/atomic-nodes/atomic-nodes.md), los pilares básicos de cualquier gráfico.
* [Las instancias de gráficos](../../compositing-graphs/creating-compositing-gra/graph-instances-sub-gra/graph-instances-sub-graphs.md), nodos compuestos, de los cuales una gran selección de contenido preestablecido está disponible en la [biblioteca de nodos](../../compositing-graphs/nodes-reference-for-com/node-library/node-library.md)
