# Paquetes de complementos

Se admiten paquetes de Python para crear complementos y ampliar la aplicación.

Son archivos individuales con una extensión sdplugin que contiene todo lo que un plugin necesita para funcionar. Para los desarrolladores, los paquetes simplifican el uso compartido y la distribución de complementos a los usuarios. Para los usuarios, los paquetes son más fáciles de instalar y administrar.

## Instalación de paquetes de complementos

![Administrador de complementos](../../assets/screenshot-from-2019-07-18-11-48-56.png "Administrador de complementos")

Los paquetes de complementos se instalan mediante <b>Administrador de complementos</b>, en el menú <b>Herramientas</b>:

1. Haz clic en el botón <b>Instalar</b> y selecciona el paquete de complementos que deseas instalar
1. El complemento se instalará en el directorio de inicio, en la ruta predeterminada para los complementos de cada sistema operativo
1. Una vez instalado el complemento, se cargará automáticamente
