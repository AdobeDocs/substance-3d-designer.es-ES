# Scripts

Es posible controlar la aplicación escribiendo complementos. Los complementos se pueden escribir en el lenguaje de scripts **Python** con la versión **3.9**. La API de Python que se proporciona en la aplicación permite acceder a muchas funciones y utilizarlas directamente desde scripts.

[Python](https://www.python.org/) es un lenguaje de secuencias de comandos ampliamente utilizado en muchos sectores. Ayuda a crear herramientas de automatización, aceleración de flujos de trabajo y administración de activos, entre otros ejemplos. Se puede acceder a la documentación de la API desde el menú principal con **Ayuda** > **Documentación de scripts...** acción.
