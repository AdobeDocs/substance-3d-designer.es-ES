# Editor de Python

Substance 3D Designer incluye un **editor de scripts**, que permite a los usuarios **probar el código de Python** directamente en Designer y obtener su **salida de consola**.

![Editor de Python](python-editor.resources/demo-pythoneditor.png "Editor de Python")

El editor incluye una característica &#39;**Buscar y reemplazar**&#39;, a la que se puede acceder en &#39;*Edición > Buscar...*&quot; en la barra de menú del editor o presionando *Ctrl+F*.

![Buscar y reemplazar en el editor de Python](python-editor.resources/demo-pythoneditor-2.png "Buscar y reemplazar en el editor de Python")

En el espíritu de las **pruebas** **propósitos** del Editor Python, los usuarios pueden probar todo el código presionando el botón &#39;*Ejecutar*&#39; en la barra de herramientas del editor (o presionando *F5*), o la **selección actual solo** presionando el botón &#39;*Ejecutar selección*&#39; (o presionando &#39;*Ctrl+Entrar*&#39;).

![Ejecutar código seleccionado en el editor de Python](python-editor.resources/demo-pythoneditor-3.png "Ejecutar código seleccionado en el editor de Python")
